MMQR (Myanmar Pay QR)

CB MMQR ဆိုသည်မှာ QR Code အခြေပြု ငွေပေးချေမှုစနစ်ဖြစ်ပြီး Myanmar Pay စံနှုန်းအတိုင်း တည်ဆောက်ထားသော QR Payment System တစ်ခုဖြစ်ပါသည်။မည်သည့် Digital Payment / Mobile Wallet မဆို အသုံးပြု၍ QR တစ်ခုတည်းဖြင့် လွယ်ကူလျင်မြန်စွာ ငွေပေးချေနိုင်သော စနစ်တစ်ခု ဖြစ်ပါသည်။

အကျိုးကျေးဇူးများ

CB MMQR အသုံးပြုခြင်းအားဖြင့် QR များစွာထားရှိရန် မလိုဘဲ MMQR တစ်ခုတည်းကိုသာ အသုံးပြုပြီး လွယ်ကူလျင်မြန်စွာ ငွေပေးချေမှု ဆောင်ရွက်နိုင်ခြင်း။

ရောင်းချရငွေ ပမာဏများအတွက် CB Pay Application တွင် ချက်ချင်း၊ အချိန်နှင့် တပြေးညီ (Real-time) လက်ခံရရှိနိုင်ခြင်း။

လက်ခံရရှိသော ငွေပမာဏများကို မိမိရွှေ့ပြောင်းလိုသော Account သို့ CB Pay မှ ချက်ချင်း မိမိကိုယ်တိုင်ပြောင်း ရွှေ့နိုင်ခြင်း။

ဆိုင်ခွဲများရှိပါက သက်ဆိုင်ရာ ဆိုင်ခွဲအလိုက် ရောင်းချရမှုများအား CB Merchant App နှင့် CB Merchant Portal များမှ အချိန်နှင့်တပြေးညီ တစ်နေရာတည်းတွင် စစ်ဆေးအတည်ပြုနိုင်ခြင်း။

Cash Handling လျော့နည်းစေပြီး လုံခြုံရေး မြင့်မားစေခြင်း။

CB MMQR သည် Commercial လုပ်ငန်းများအတွက် အထူးသင့်လျော်ပြီး စနစ်တကျ စီမံခန့်ခွဲနိုင်ခြင်း။

ဝန်ဆောင်မှုများ

ဘဏ်အကောင့်ဖွင့်ရန်အတွက် လိုအပ်သောစာရွက်စာတမ်းများ ကောက်ခံပေး၍ A/C ဖွင့်ပြီးသည် အထိ ဆောင်ရွက်ပေးခြင်း။

MMQR Agreement ချုပ်ပြီးသည်နှင့် (၂) ပတ်အတွင်း Merchant ဆိုင်များထံ QR များ ပို့ပေးနိုင်ရန် ဝန်ဆောင်မှု ပေးခြင်း။

Static QR Stand များကို အခမဲ့ ပြုလုပ်ပေးခြင်း။ လိုအပ်ပါက POS Dynamic QR, In-App QR/ Ecommerce Dynamic QR များအတွက်ပါ ဝန်ဆောင်မှုပေးခြင်း။

Transaction များကို အချိန်နှင့် တပြေးညီကြည့်နိုင်ရန် Merchant App/ Merchant Portal များတွင် Outlet, Cashier များခွဲပြီး တည်ဆောက် ပေးထားသဖြင့် Transaction Report များထုတ်ယူနိုင်ခြင်း။

Merchant App/ Merchant Portal အသုံးပြုပုံများကို အခမဲ့Training ပေးခြင်းများ ဆောင်ရွက်ပေးခြင်း။

လိုအပ်ပါက MMQR အရောင်းစာရင်း Detail Transactions များကို သက်ဆိုင်ရာ Merchants များထံ အခမဲ့ Email ပို့ပေးခြင်း။

24/7 Merchant Support Team ရှိပါသဖြင့် မြန်ဆန်သော Service ၊ တိကျသောလုပ်ဆောင်မှု နှင့် ၀န်ဆောင်မှု ပေးခြင်း။

MMQR Transactions များအတွက် Merchants များ ငွေထုတ်လိုပါက အနီးစပ်ဆုံး CB ဘဏ်ခွဲများတွင် ငွေထုတ် ယူနိုင်ရန် စီစဉ်ဆောင်ရွက်ပေးခြင်း။

MMQR လျှောက်ထားရန် အောက်ပါအချက်များလိုအပ်ပါသည်

လျောက်ထားသူ၏မှတ်ပုံတင် မိတ္တူ

လုပ်ငန်းအမည် (QR Code ဖတ်သည့်အချိန်တွင် ဖော်ပြရန်)

CB MMQR ကို အသုံးပြုမည့် လုပ်ငန်းတည်နေရာ

လုပ်ငန်းအမျိုးအစား (ဥပမာ – စားသောက်ဆိုင်၊ စတိုးဆိုင်၊ fashion shop )

ဆက်သွယ်ရန် ဖုန်းနံပါတ်

လိုက်နာရမည့်စည်းမျဉ်း၊ စည်းကမ်းများ

သက်ဆိုင်ရာ Wallet မှ ပေးပို့သည့် Transaction Record တွင် Transaction Success ဖြစ်ကြောင်းပါရှိရမည်။

Transaction ပြုလုပ်ရာတွင် E2E ID ပေါ်ရပါမည် မဖြစ်မနေ မှတ်သားထားရန် လိုအပ်ပါသည်။ ပြဿနာ တစုံတရာ ဖြစ်ပါက ထို E2E ID ဖြင့် စစ်ဆေးရန်ဖြစ်သည်။

Merchant App တွင် ပြုလုပ်ထားသော Transactions များသည် Amount/ Date / Time နှင့် Transaction ID ပြည့်စုံစွာ ဖော်ပြထားရမည်။

Transaction အတည်ပြုခြင်းကို Merchant App နှင့် သက်ဆိုင်ရာ Wallet Record နှစ်ဖက်စလုံးတွင် ကိုက်ညီမှုရှိကြောင်း စစ်ဆေးပြီးမှသာ အရောင်းအဝယ် ပြီးစီးသည်ဟု သတ်မှတ်ရပါမည်။

ငွေပေးချေမှု ကန့်သတ်ချက်

Wallet User – တစ်ရက်လျှင် တစ်ကြိမ်အများဆုံး ငွေပေးချေမှု ပမာဏ MMK 10,000,000 (၁၀၀ သိန်း)

Merchant User – လက်ခံနိုင်သည့် ငွေပမာဏ ကန့်သတ်ချက်မရှိ

MMQR အသုံးပြုနိုင်သည့် ပုံစံများ

1.	Static QR

ငွေပေးချေမည့် အမောင့်ကို Customer ဘက်မှ ကိုယ်တိုင် ရိုက်ထည့်ပေးရသည်။

2.	POS Dynamic QR

Merchant ဘက်မှ ပေးချေရမည့် ငွေအမောင့်ကို စနစ်ထဲတွင် ရိုက်ထည့်ပေးရသည်။

3.	In-App QR/ Ecommerce Dynamic QR

Application အတွင်းမှ တိုက်ရိုက် Scan ပြုလုပ်၍ ငွေပေးချေနိုင်သော စနစ်ဖြစ်သည်။ Ecommerce ငွေပေးချေမှု လက်ခံသော Website များတွင်လည်း အသုံးပြုနိုင်ပါသည်။

အရောင်း စီမံခန့်ခွဲမှု

Sale Transaction များပြုလုပ်နိုင်ခြင်း။

ကုန်ပစ္စည်းအရောင်း Transaction များကို Merchant App & Merchant Portal တွင် အသေးစိတ်စစ်ဆေးနိုင် ခြင်း။

ငွေအမောင့်မှားယွင်းပါက Merchant App တွင် Refund (Full / Partial Refund) နှင့် Merchant Portal တွင် Refund Request တင်ခြင်းများ ပြုလုပ်နိုင်ခြင်း။
