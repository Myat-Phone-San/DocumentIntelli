E-Commerce (Merchant)

E-commerce ဆိုသည်မှာ Internet / Online electronic ငွေပေးချေသည့် နည်းလမ်းကို အသုံးပြုကာ ၀န်ဆောင်မှုများနှင့် ကုန်ပစ္စည်းများကို Website မှတဆင့် ရောင်းချခြင်းကို ဆောင်ရွက်ပေးသည့် စနစ်ဖြစ်ပါသည်။ ကမ္ဘာတစ်ဝှမ်းလုံးရှိ UPI, JCB, Visa, MasterCard နှင့် MPU ကိုင်ဆောင်ထားသည့် ကတ်ပိုင်ရှင်များသည် မြန်မာနိုင်ငံရှိ အစိုးရဌာနများ ၊ စီးပွားရေးလုပ်ငန်း အဖွဲ့အစည်းများ ၊ ဟိုတယ်ကြီးများ၊ လေကြောင်းလိုင်းများနှင့် Online Shopping Site အရောင်းဆိုင်များတွင် Internet/Online မှတဆင့် ၀ယ်ယူမှုအတွက် ငွေပေးချေနိုင်ရန် CB Bank E-commerce ၀န်ဆောင်မှုများကို ပြုလုပ်ပေးနေပါသည်။

အကျိုးကျေးဇူးများ

Online မှလွယ်ကူလျှင်မြန်စွာ ငွေပေးခြေနိုင်ခြင်း။

ကုန်သည် ဘက်မှ ငွေကြေးလုံခြုံစိတ်ချမှုရှိခြင်း။

ဝယ်ယူသည့် ပစ္စည်းတန်ဖိုးကို တိကျစွာပေးချေနိုင်ခြင်း။

ကုန်သည် ဘက်မှ စာရင်းများကို လွယ်ကူရှင်းလင်းစွာ စစ်ဆေးကြည့်ရှုနိုင်ခြင်း။

ဝန်ဆောင်မှုများ

အကောင့်ဖွင့်ရန်အတွက် လိုအပ်သောစာရွက်စာတမ်းများ ကောက်ခံပေး၍ A/C ဖွင့်ပြီးသည် အထိ ဆောင်ရွက်ပေးခြင်း။

Website စမ်းသပ်ခြင်းများ၊ အသုံးပြုပုံများကို IT Team မှ ဆောင်ရွက်ပေးခြင်း။

Website Secure ဖြစ်စေရန်အတွက် အကြံဥာဏ်များပေးခြင်း။

Transaction များကို အချိန်နှင့် တပြေးညီကြည့်နိုင်ရန် Merchant Portal များတည်ဆောက် ပေးထားခြင်း။

မြန်ဆန်သော Service ၊ တိကျသောလုပ်ဆောင်မှု နှင့် ၀န်ဆောင်မှုပေးခြင်း။

တစ်ရက်စာ အရောင်းစာရင်း Detail Transactions များကို သက်ဆိုင်ရာ Merchants များထံ နေ့စဉ် အခမဲ့ Email ပို့ပေးခြင်း။

လက်ခံနိုင်မည့် ကတ်အမျိုးအစားများ

မည်သည့် Bank မှမဆို ထုတ်ဝေထားသော Card အားလုံး အသုံးပြုနိုင်ခြင်း။

(MPU, UPI, JCB, Visa, Master)

အခြားနည်းလမ်းအဖြစ် CB MMQR ကိုလည့်းထည့်သွင်း အသုံးပြုနိုင်ခြင်း။

လိုအပ်ချက်များ

ကုန်သည် တွင် Online Website တစ်ခုရှိရန် လိုအပ်ပါသည်။

လုပ်ငန်းစဉ်များအတွက် Ecommerce Gateway နှင့် Integration ပြုလုပ်ရန် Website Developer Team တစ်ဖွဲ့ ရှိရန်လိုအပ်ပါသည်။ Website အားရေးသားသည့် မူရင်း Developer  အစား အခြား Developer Team ကို အသုံးပြုမည်ဆိုပါက မူရင်း Website ၏ Source Code ကို လက်ခံရရှိထားရန် လိုအပ်ပါသည်။

လိုက်နာရမည့်စည်းမျဉ်း၊ စည်းကမ်းများ

CB Bank တွင် Current A/C တစ်ခုဖွင့်ရန် လိုအပ်ပါသည်။ (Joint A/C)

MPU – MMK A/C, Visa/Master/JCB/UPI – MMK & USD A/C

ကုန်သည် သည် CB Bank နှင့် စာချုပ်ချုပ်ဆိုရန် လိုအပ်ပါသည်။ (2 Years)

Visa, Master, JCB နှင့် UPI များသည် ( 3DS Transactions ) များဖြစ်ရပါမည်။ ( Non- 3DS Transactions)  များ ဖြစ်ပါက ဝန်ဆောင်မှုပေးနိုင်မည် မဟုတ်ပါ။

အရောင်း စီမံခန့်ခွဲမှု

Sale Transaction များပြုလုပ်နိုင်ခြင်း။

ကုန်ပစ္စည်းအရောင်း Transaction များစစ်ဆေးနိုင်ခြင်း။

ငွေအမောင့်မှားယွင်းပါက Refund (Full / Partial Refund) ပြုလုပ်နိုင်ခြင်း။
